# DPIP — Decentralised Platform for Public Infrastructure

A transparent, open-source web platform for government tendering and public infrastructure contracts. Government officials post tenders, contractors bid, the platform allocates contracts to the highest bidder, and everything is publicly displayed.

## 🔗 Live Demo

Open https://imran7833.github.io/CivicChain/ directly in any browser — no server or build step required.

## 🎯 Features

### For Government (Admin)
- Post new infrastructure tenders with budget, category, location, and deadline
- View all bids received on each tender
- Allocate contracts to the highest bidder after the deadline
- Close bidding early if needed
- Full dashboard with stats and pending allocation alerts

### For Contractors
- Browse and filter all active tenders
- Submit bids with amount and proposal notes
- Track your bid history and win/loss status
- See where you rank vs. other bidders
- Dashboard showing all your bids and outcomes

### For Citizens (Public)
- View all tenders and their current status — **no login required**
- See awarded contracts, winning bids, and winning contractors
- Full project timeline for every tender
- Completely transparent bid history
